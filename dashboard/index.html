Services

One ICMP probe series per point (10 packets), one HTTP GET per service, both time-boxed. History is a rolling window in data.json; the page is static and re-reads it on load.
Metrics are mirrored to a Prometheus pushgateway as netwatch_up, netwatch_loss_pct, netwatch_latency_avg_ms, netwatch_jitter_ms, netwatch_service_up (job label netwatch).
Latency is the ICMP average over 10 packets. Figures for anything that is not on the collector's own segment include the path to it, so they measure the route, not the device alone.
